# EmptyState

An empty state fills a bay or page when there is nothing to show, says why, and offers the one action that fixes it.

- Structure: `cor-empty` (dashed frame filled with the `line` hatch, COR's "no signal") > `cor-empty__card` (rail, `cor-tag` status, `empty-title`, one sentence, one key).
- Three cases, each with its own copy:
  - Nothing connected (Analytics, Data, Reports): "Nothing is patched in yet." + Connect a platform.
  - Filters return nothing: "No data for Mar 1 → Mar 7." + "Widen the window" key that resets the range.
  - Feature unused (no alerts, no saved reports): say what it does in one sentence + Create key.
- Never show zeros or flat lines in place of an empty state; "$0 spend" means something different from "no data".
